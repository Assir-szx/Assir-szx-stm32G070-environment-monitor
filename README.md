# STM32G070 环境监测终端

基于 STM32G070CBT6 的低功耗环境监测系统，实现温湿度、光照、电压采集，OLED 显示，蜂鸣器报警，以及 ESP01S WiFi 数据上传。

## 硬件平台
- MCU：STM32G070CBT6（Cortex-M0+，64MHz，128KB Flash，36KB RAM）
- 传感器：DHT11（温湿度）、光敏电阻（光照）、ADC（电压检测）
- 显示：0.96寸 OLED（I2C）
- 通信：ESP01S WiFi 模块（UART + AT指令）
- 报警：有源蜂鸣器（GPIO）
- 调试：UART1 重定向 printf，串口日志追踪

## 软件架构
采用分层设计，代码模块化：
- **驱动层**：DHT11（单总线）、ADC、OLED（I2C）、UART
- **中间件**：环形缓冲区（串口接收）、AT指令解析
- **应用层**：数据采集、显示、报警、WiFi上传

## 核心技术难点与解决方案

### 1. DHT11 单总线时序捕获
- **问题**：软件延时读取时，串口中断打断导致时序错位，OLED 显示 0。
- **解决**：改用 **TIM15 硬件定时器输入捕获**，精确测量高电平时长（26~28µs 判 0，70µs 判 1）。
- **结果**：校验通过率从不足 50% 提升至 100%。

### 2. ESP01S 供电不足导致频繁掉线
- **问题**：ESP01S 发射峰值电流 >300mA，板载 LDO 供电不足，模块反复重启。
- **解决**：改用**独立 LDO 供电 + 100µF 电容**，保证瞬时电流供应。
- **结果**：通信恢复稳定，不再掉线。
